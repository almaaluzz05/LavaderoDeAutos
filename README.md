🚗 ALMA Detailing

ALMA Detailing es una página web creada para un lavadero de autos, pensada para que los clientes puedan conocer los servicios disponibles y realizar una reserva de manera sencilla.

📌 Descripción

El proyecto consiste en una página web para un lavadero y servicio de detailing de vehículos. Cuenta con diferentes opciones de limpieza y mantenimiento, permitiendo al usuario seleccionar los servicios que necesita y consultar el precio total.

✨ Funcionalidades

* 🏠 Página de inicio con información del lavadero.
* 🧽 Sección de servicios disponibles.
* 🛒 Carrito de servicios.
* 💰 Cálculo del precio total de los servicios seleccionados.
* 📅 Sistema de reserva.
* 👤 Formulario con los datos del cliente.
* 🚘 Registro de información del vehículo.
* 📞 Sección de contacto.
* 📱 Diseño adaptable a distintos dispositivos.

🧼 Servicios

Entre los servicios disponibles se encuentran:

* Lavado exterior
* Limpieza interior
* Lavado completo
* Limpieza de motor
* Limpieza profunda
* Limpieza de tapizados
* Pulido y encerado
* Detailing

🛠️ Tecnologías utilizadas

* HTML5 → estructura de la página.
* CSS3 → diseño y estilos.
* JavaScript → funcionalidades e interacción del carrito y reservas.

🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo index.html en un navegador.
4. También se puede utilizar Visual Studio Code con la extensión Live Server para visualizar la página.

🎯 Objetivo

El objetivo del proyecto es desarrollar una página web funcional y fácil de utilizar para un lavadero de autos, aplicando conocimientos de desarrollo web, diseño, formularios, JavaScript y manejo de eventos.
